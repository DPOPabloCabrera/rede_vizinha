# Privacy by Design

Regras herdadas da especificação:
1. Telefone não deve ser exposto em texto plano na interface pública.
2. Contato deve ocorrer por Deep Link do WhatsApp.
3. Avaliações exibem identificadores genéricos, como nome + torre.
4. Exclusão/anonimização deve respeitar retenção e obrigações legais.
5. Controle de acesso deve respeitar o papel do usuário e o condomínio.
